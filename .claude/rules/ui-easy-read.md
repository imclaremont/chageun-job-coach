# 화면 규칙 — 쉬운 말과 접근성

근로자 화면(`/work` 이하)은 발달장애·경계선지능 사용자가 혼자 쓸 수 있어야 한다. 코치 화면(`/coach` 이하)은 일반 업무 도구 기준이다

## 근로자 화면 — 문구

- 한 문장에 한 가지 내용만, 문장은 짧게 (40자 이내 권장)
- 일상에서 쓰는 쉬운 낱말 사용, 한자어·외래어·줄임말·비유 지양
- '~해요' 체의 부드러운 존댓말
- 무엇을 하면 되는지 긍정형으로 안내 ("뚜껑을 닫아요"), 부정형 지시 지양
- 꾸짖거나 재촉하는 표현 금지, 오류 안내도 쉬운 말로 다음 행동을 알려 준다
- 숫자와 양은 구체적으로 ("얼음을 컵 끝까지 넣어요")

## 근로자 화면 — 구성

- 한 화면에 한 가지 행동만 요구한다
- 지금 할 일을 가장 크게 보여 주고, 전체 중 몇 번째인지 표시한다
- 본문 글자는 20px 이상, 핵심 지시는 28px 이상
- 버튼은 크게 (높이 56px 이상), 글자와 아이콘을 함께 쓴다
- 주요 버튼은 화면 아래 같은 위치에 고정해 매번 찾지 않게 한다
- 읽어 주기(음성) 버튼을 단계마다 제공한다

## 공통 접근성

- 색만으로 정보를 전달하지 않는다 (아이콘·글자 병행)
- 글자와 배경의 명도 대비는 WCAG AA 이상
- 터치 영역은 48px 이상
- 모든 상호작용 요소에 접근 가능한 이름 제공 (`aria-label` 등), 이미지에는 `alt`
- 움직임은 최소화하고 `prefers-reduced-motion`을 존중한다
- 로딩·오류·빈 상태를 빠뜨리지 않는다

## 데이터

- 화면에 보이는 예시 데이터는 전부 가상 데이터
- AI가 만든 내용에는 AI 생성 표시를 붙인다
