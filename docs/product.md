# 차근 — 제품 정의

## 한 줄

발달장애·경계선지능 청년이 첫 직장에서 새 업무를 스스로 익히도록, 업무 매뉴얼을 쉬운 단계 카드로 바꾸고 막힐 때 곁에서 코칭하는 AI 직무 코치

## 사용자

| 구분   | 누구                                                   | 원하는 것                                                 |
| ------ | ------------------------------------------------------ | --------------------------------------------------------- |
| 근로자 | 첫 직장에 들어간 발달장애(지적·자폐성)·경계선지능 청년 | 물어볼 사람이 없어도 지금 할 일을 알고 끝까지 해내기      |
| 코치   | 직무지도원·근로지원인·매장 관리자                      | 단계 자료를 손으로 만들지 않고, 여러 근로자를 한눈에 보기 |

## 풀려는 문제

- 발달장애 청년은 취업 자체보다 취업 뒤 정착에서 어려움을 겪는다. 새 업무 절차를 익히고 돌발 상황에 대응하는 일이 특히 어렵다
- 곁에서 알려 주는 직무지도원 지원은 기간이 정해져 있고 비용이 커서, 지원이 끝나면 공백이 생긴다
- 기존 단계 안내 도구는 보호자나 교사가 카드를 하나하나 만들어야 해서, 매장마다 다른 실제 업무를 담기 어렵다

## 핵심 흐름

1. **코치 — 가이드 만들기**: 매장의 실제 업무 매뉴얼(글)을 넣는다 → AI가 쉬운 단계 카드로 바꾼다 → 코치가 단계마다 근거와 경고를 확인하고 고친 뒤 승인한다
2. **근로자 — 일하기**: 오늘 할 일을 고른다 → 한 화면에 한 단계씩 큰 글씨와 그림으로 본다 → 끝나면 '다 했어요', 막히면 '잘 모르겠어요'를 누른다
3. **근로자 — 막힘 코칭**: AI가 그 단계를 더 쉬운 말로, 더 잘게 나눠 알려 준다. 알 수 없는 질문에는 지어내지 않고 사람을 부르게 한다
4. **코치 — 지켜보기**: 근로자별 진행 상황, 자주 막히는 단계, 사람 도움 요청을 한눈에 본다

## AI 에이전트

| 에이전트    | 하는 일                                                                                   | 사람의 역할                   |
| ----------- | ----------------------------------------------------------------------------------------- | ----------------------------- |
| 가이드 생성 | 매뉴얼 분석 → 단계 분해 → 쉬운 말·근거·위험 요소 자체 점검 → 기준에 못 미치면 다시 쓰기   | 코치가 검수·수정·승인         |
| 막힘 코칭   | 승인된 단계와 원문 안에서 도구를 써서 답하기: 단계 다시 설명, 더 잘게 나누기, 사람 부르기 | 코치가 호출에 응답, 기록 확인 |

## 안전장치

- AI가 만든 단계는 코치가 승인해야 근로자에게 보인다
- 단계마다 원문 매뉴얼의 근거 문장을 붙이고, 근거가 원문에 실제로 있는지 코드로 대조한다
- 쉬운 말 기준은 프롬프트뿐 아니라 코드 검사기로 다시 확인한다
- 코칭 답변은 승인된 내용 밖으로 나가지 않고, 모르면 사람을 부른다
- AI 호출이 실패해도 승인된 단계는 그대로 볼 수 있다
- AI가 만든 내용에는 AI 생성 표시를 붙인다
- 실제 개인정보를 쓰지 않는다. 예시 데이터는 전부 가상이다

## MVP 범위

마감(2026-11-23 17:00)까지 직무 하나가 처음부터 끝까지 도는 흐름을 완성한다

- 글 매뉴얼 입력과 AI 단계 변환, 검수·승인
- 근로자 단계 화면: 큰 글씨, 그림 기호, 읽어 주기(브라우저 음성 합성)
- '잘 모르겠어요' 코칭과 사람 부르기
- 코치 대시보드: 진행 상황, 막힌 단계, 도움 요청
- 익숙해진 근로자를 위한 간단 보기 (단계 묶어 보기)
- 시연용 가상 매뉴얼 1종 (카페 아이스 음료 만들기)

## 범위 밖

- 영상·음성 매뉴얼 입력
- 로그인·계정·권한 관리, 여러 사업장 관리
- 실제 근로자 개인정보 처리
- 네이티브 앱

## 용어

| 용어      | 뜻                                         | 코드     |
| --------- | ------------------------------------------ | -------- |
| 가이드    | 업무 하나를 단계로 나눈 묶음               | `guide`  |
| 단계      | 근로자가 한 번에 하는 행동 하나            | `step`   |
| 수행      | 근로자가 가이드를 한 번 따라 하는 기록     | `run`    |
| 도움 요청 | '잘 모르겠어요' 또는 사람 부르기           | `help`   |
| 코치      | 가이드를 만들고 승인하는 관리자·직무지도원 | `coach`  |
| 근로자    | 가이드를 따라 일하는 사용자                | `worker` |
